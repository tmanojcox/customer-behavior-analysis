## Project Workflow

### 1️⃣ Python & EDA

* Load and inspect data
* Analyze data types and distributions
* Identify missing values and duplicates
* Perform exploratory analysis

### 2️⃣ Data Cleaning

* Handle missing values
* Remove duplicates
* Correct data types
* Standardize and transform data

### 3️⃣ SQL Analysis

* Load cleaned data into SQL databases
* Perform aggregations and joins
* Use CTEs and window functions
* Calculate KPIs and identify trends

### 4️⃣ Power BI

* Build data model
* Create DAX measures
* Develop interactive KPIs and visualizations
* Add slicers, filters, and drill-downs

### 5️⃣ Reporting & Presentation

* Document key findings and recommendations
* Create a professional presentation using **Gamma**

## ▶️ How to Run

```bash
git clone <repository-url>
cd data-analytics-project
pip install pandas numpy matplotlib seaborn
```

1. Run the Python/Jupyter Notebook.
2. Execute the SQL queries in PostgreSQL, MySQL, or SQL Server.
3. Open the `.pbix` file in Power BI.
4. Review the report and presentation.
